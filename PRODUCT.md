# Product

## Register

product

## Users

One person: Adam, a developer/operator running multiple coding agents against a local knowledge base, using the dashboard for 8-hour working sessions. Context: dark room, long sessions, keyboard-heavy. The planner (Today + Flow) is his daily driver; the constellation and project hubs are the knowledge surfaces. Coding agents are the other "users" but they use the MCP gateway, not the UI.

## Product Purpose

The Grimoire is a local shared knowledge base plus a daily planner. The UI's job: capture fast (tasks, notes, documents), review what agents wrote, and plan the day (Eisenhower matrix + generated timeline). Success is the tool disappearing into the daily routine; no manual reloads, no lost edits, no dead ends.

## Brand Personality

Arcane, calm, precise. FFXV-adjacent grimoire atmosphere on the chrome (Cinzel headers, gold on near-black, rune glows), plain readable Spectral body everywhere content lives. Loading copy may be thematic ("inscribing the grimoire"); errors stay plain and actionable.

## Anti-references

- Stylized-into-illegibility content panels. Atmosphere never wins over readability.
- Generic SaaS dashboard chrome (light gray cards, hero metrics, cream backgrounds).
- Status communicated with new hues. Four rune colors is the ceiling; status is glow (steady / faint pulse / red rim).

## Design Principles

1. Atmosphere on the chrome, legibility on the content. The one rule that keeps 8-hour sessions usable.
2. Capture must be faster than the thought decays: chat bar, + buttons, inline edits; no flow requires more than one dialog.
3. Live by default: views refresh themselves, but never clobber in-flight user input.
4. The schedule is a proposal; the goals are the constant. Destructive actions confirm; everything else is instant and, where possible, undoable.
5. Sentence case everywhere; no em-dashes in copy.

## Accessibility & Inclusion

Dark-only by design (glow effects do not read on light). Respect prefers-reduced-motion for pulses/spins. Interactive targets keyboard-reachable; contrast: body text #e5e0ee on #0c0b14 passes AAA; muted text reserved for secondary labels.
